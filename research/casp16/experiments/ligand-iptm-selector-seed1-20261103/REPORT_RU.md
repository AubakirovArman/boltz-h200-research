Поза заранее выбирается по максимальному ligand_iptm среди пяти исходных предсказаний; экспериментальные значения affinity не используются. Все 140 пар сохранены. Для rank0/rank1 переиспользованы уже полученные seed1-прогнозы, дополнительно рассчитаны 23 позы rank2–4. Это не измерение скорости полного решения.

Rank0/rank1 values come from the same fixed seed1 shard controls. Fresh ranks2-4 use two smaller seed1 CLI calls; RNG streams differ. This is an exploratory selector test, not exact matched-noise isolation.

Малое различие R нельзя уверенно приписать только позе: последовательности RNG новых малых CLI отличаются от контроля. Структурная гипотеза исследовательская; независимый набор белков не проверялся.

## Проверки и ресурсы

Все процессы завершились с кодом 0. Итоговая оценка содержит все 140 исходных ID. Численные результаты пересчитаны независимо с точностью 1e-12. Официальный исходник Boltz не менялся; исходные прогнозы сохранены. Это проверка исследовательского эксперимента, не официальный test suite.

Время серии на общем H200: 1309.98 с. Оно включает ожидания и совместную работу с другой серией; из него нельзя выводить ускорение модели.
